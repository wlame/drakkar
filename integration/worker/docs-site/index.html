Ripgrep Pipeline Handbook

Operator notes for the integration harness worker: what it scans, where the results go, and what to do when a part of it misbehaves. The worker serves this site itself, so it is reachable from any operator UI page and from the book icons next to the surfaces it documents.

  • Scanning — scan targets, modules, and window ranges.
  • Operations — sinks, storage, and routine checks.

How you got here

Every book icon in the operator UI opens one page of this site in a drawer. The mapping lives in the worker's own configuration (ui.docs.anchors in integration/worker/drakkar.yaml): a task label, a sink instance, a timeline event type, or a declared page is bound to a path in this directory. Nothing in this site knows about the UI, and the UI knows nothing about this site beyond those paths.
